## 你大概遇到过这些时刻

- **AI 回了一大段，框架正确、信息量为零。** 它说了"要综合考虑多方面因素"，但没说该算哪个量。
- **它用了一个你从没说过的假设，而且没告诉你。** 等你发现方案全错，才知道前提被人替你定了。
- **你问 A，它答 B。** 因为它把你说的手段当成了目的（"怎么换管道" ≠ "怎么降低漏损"）。
- **你让它严谨一点，它就开始无限下拆。** 拆到集合论，离问题已经很远了。

这四个坑有一个共同原因：**隐式判断没有被逼到台面上。** 这个技能就是为这件事设计的。

## 它到底做了什么不一样的事

它**不提供任何领域知识**。它做的是三件事：

**一、把问题逼成显式对象。** 原语、公设、假设、目标、约束、结论——公理化在这里不是用来做证明的，而是用来**强制显式化**。隐式判断一旦被写成显式对象，"我其实没把握"的地方就会自己浮出来。

**二、把每个对象变成能力检索键。** 对每条目标、约束、假设，强制写出：它属于哪个领域、需要该领域给出什么、现在能不能调用。**有了键，才谈得上精准调用专业能力。**

**三、把该问的和该查的分出去。**

- 口径、约束可动性、数据可得性——AI 推不出来，**去问提问者**（给候选项，一次只问最关键的 1–3 个）；
- 提问者给的前提——**不是免检输入**，逐条过一致性/独立性/必要性/表述精度/可检验性/崩溃测试。

## 三段脊柱

```
A 前置层 · 精准：验收判据 → 目标/约束分离 → 问题重定义 → 假设排序 → 能力调用清单 → 向提问者提问 → 定停止层
B 论证层 · 严密：每步写成 演绎 [领域|依据] / 归纳 [warrant|强度|撤销条件] / 机制性断言（不入结论）
C 收敛层 · 高效：定位瓶颈 → 反证优先 → 两本账（能力缺口 / 机制性断言）→ 迭代回 A → 结论先行交付
```

## 如果你是欧几里得，你会选什么当公设？

拿到一堆几何事实，你要挑出不可再约的基础承诺。**选什么、不选什么，本身就是设计。**

**三条选择标准**

1. **只选"可作／可断言"，不选"可证"。** 公设 = 允许做什么（画直线、延长、作圆），公理 = 允许断言什么（等量代换）。**凡能证明的，一律不放进公理**——放进去是偷懒，也会让系统失去解释力。
2. **尽量少。** 宁可让后面的命题多绕几步，也不多加一条前提。每多一条，适用范围就被悄悄削窄一分。
3. **要能生成。** 五条公设全是**构造性操作**，这保证一切存在性都有出处：凡被断言存在的对象，都能追到某一次"作"上。

**一个不情愿的选择**

第五公设（平行公设）欧几里得自己就不满意——它明显不如前四条自明，却删不掉。两千年后人们证明：**删掉它或换掉它，得到的不是错误，而是另一个自洽的宇宙。**

> **选什么当公设，决定了这个系统能说什么。**
> 你的"第一性原理"不是找到的，是**选**出来的——而选择有标准。

技能里的 A 前置层做的正是这件事：把目标、约束、假设显式化，再给每条标注 硬约束／可放宽／可替换。

## 如果你是牛顿，你会问什么？

《原理》是欧氏方法在物理里最成功的移植，也是对这套方法最清醒的反思。下面七个问题，他都在书里回答过。

**Q1　这些公理从哪来？**
不是自明的，是从**现象**里归纳出来的。他明说时间与空间不是"众所周知的"，而是在**公设**它们。

**Q2　从现象归纳出来的结论，凭什么信？**
第三卷规则四：视为真或极近于真，**直到有其他现象使它更精确，或出现例外**。这就是技能要求"归纳步必须写撤销条件"的来源。

**Q3　解释不了的东西怎么办？**
> 凡不是从现象中推出来的，就得称之为假设……在实验哲学中没有位置。

他算出了平方反比，却始终不说引力之因。**他拒绝的不是跳跃，是把落点说成起点。** 这就是技能里第二本账（机制性断言）的来源。

**Q4　数学与物理的边界在哪？**
卷一、卷二纯数学，卷三才是世界体系。**公理化本身不产生关于世界的知识，它只组织已经获得的知识。**

**Q5　定义可以先立吗？**
可以，但必须承认其中有些**无法直接测量**（绝对时间、绝对空间）。连牛顿都要显式声明不可测量的原始设定——对应技能里的"原语"与"停止层"。

**Q6　这套规则会不会变？**
会。三版《原理》，推理规则从三条加到四条。**连公理化的政策都随认识修订。**

**Q7　先分析还是先综合？**
分析在前（从现象上溯到原理），综合在后（从原理下推到现象）。只有综合没有分析，得到的是一套漂亮但什么也不说的体系。

**还有一条他没写成规则，但一直在做**：缺少形式工具时，建立局部约定并声明适用范围——没有极限理论，他就立了十一条「首末比」引理。

## 适用领域

这个技能是跨领域的**协议**，不绑定学科。适配条件只看问题形态。

**三条适配信号（同时出现时收益最大）**

1. 隐含假设多——结论严重依赖没人说出口的前提；
2. 错框架代价高——模型选错，下游全部白做；
3. 需要外部能力——靠常识推不出来，得调用具体领域的结论或数据。

**适配良好**：工程建模（传热、流体、结构、控制）｜运筹与决策（路径规划、资源分配、不完全信息下的序贯决策）｜统计与因果（实验设计、误差传播、测量标定）｜临床决策（鉴别诊断、证据等级、风险收益）｜经济与商业（定价、投资、政策评估）｜法律与政策（构成要件、举证责任——本质就是公理化）｜软件架构（遗漏的非功能需求＝未声明的公理）｜安全与可靠性（故障树、威胁建模的前提）｜论文评审（隐含前提与循环论证）

**不适配**：纯事实查询、检索、翻译、格式转换（直接答）；创意与发散，如写作、设计、头脑风暴（那里没有真/假，公理化会扼杀发散）；主观审美与情感支持；已被严格定义好、只需计算的问题（直接算）。

**判断口径**：看问题是否**良定义**，以及**错框架的代价**有多高。良定义且代价低 → 直接做；定义模糊或代价高 → 用这个技能。

## 一个真实用例

分析过一道数学建模赛题（无线电干扰源的自动定位与清除）。前置层直接逼出两个决定性结论：

1. **判据是"100% 清除"，不是平均指标**——这决定方案必须包含覆盖性保证，不能只做贪心；
2. **瓶颈是移动距离，不是检测精度**——时间预算换算成约 6000 m 的移动量，方案方向随之变成"压缩锚点数量与频道切换次数"。

在自建虚拟模拟器上，优化后的策略把总时间从 **107.7 分钟压到 68.3 分钟**（清除率 100%），程序运行时间约 5 ms / 案例。

## 历史基准：五条公设与五条公理

**公设**（允许做什么）

1. 过两点作一直线；
2. 有限直线可延长；
3. 以任意中心、任意距离作圆；
4. 直角皆相等；
5. 平行公设。

**公理**（允许断言什么，即共同概念）

- 等于同量的量相等；
- 等量加等量，和相等；
- 等量减等量，差相等；
- 可重合的图形相等（叠合）；
- 整体大于部分。

分工很清楚：公设管**操作**（能画什么），公理管**逻辑**（能推什么）。技能沿用这个分工，但**不携带这些具体的几何内容**——它借用的是结构。

## 最小样例：I.1 在给定线段上作等边三角形

全书第一个命题，只用到三条公设和一条公理，是理解"公理化"成本最低的样本。它的六段结构，就是 `SKILL.md` 里 B 论证层的完整骨架。

**命题陈述**　在给定的线段上作一个等边三角形。
**设定**　设 AB 是给定的线段。
**规定**　求作以 AB 为边的等边三角形。
**构造**（只用公设）：以 A 为心、AB 为半径作圆（公设 3）；以 B 为心、BA 为半径作圆（公设 3）；设两圆交于 C，连接 AC、BC（公设 1）。
**证明**：A 是圆心 ⇒ AC = AB；B 是圆心 ⇒ BC = AB；由"等于同量的量相等" ⇒ AC = BC；故 AC = BC = AB，三角形 ABC 为等边三角形。
**结论**　在给定线段上作出了等边三角形，这正是所要证明的。

**审计**　这里藏着一个著名的缺口：「两圆必有交点」并不在这五条公设里，它依赖连续性，直到希尔伯特补充连续公理才被显式化。这正是技能里"完备性"检查要抓的东西——一个看起来天经地义的步骤，其实是一条未声明的假设。
