# euclid-elements

一个从欧几里得《几何原本》的公理化方法中提炼出来的**解题思维引擎**（Codex / Agent Skill）。

它的目标不是把论证做得更严密，而是**把问题解得又快又准**。严密只是中段的手段，不是终点。

## 解决什么问题

大多数“从第一性原理出发”的尝试会掉进两个坑：

- **拆得不够**：沿用别人给的假设，于是只在别人的框架里打转。
- **拆得太多**：一路下挖到集合论和逻辑，反而离问题越来越远，既不准也不快。

这个技能用「前置 → 论证 → 收敛」三段脊柱把两端都框住。

## 三段脊柱

```
A 前置层 · 精准：验收判据 → 目标/约束分离 → 问题重定义 → 假设排序 → 定停止层
B 论证层 · 严密：按复杂度分层启用欧氏骨架（原语/公设/证明链/三准则）
C 收敛层 · 高效：定位瓶颈 → 反证优先 → 失败迭代回 A → 结论先行交付
```

- **A 前置层**管“精准”：先写清什么算解决了、要优化的目标与不可违反的约束分别是什么、问题本身是否问对、哪些假设最值得先放宽、拆到哪一层就该停。
- **B 论证层**管“严密”：只有在问题足够复杂时才启用完整的欧氏骨架（原语 → 公设 → 证明链 → 一致性/独立性/完备性三准则）；简单问题不建公理化。
- **C 收敛层**管“高效”：找出真正的瓶颈（支配性约束），先用最小成本找反例证伪，失败就回到 A 修订假设，最后结论先行交付。

## 安装

把整个目录放进你的 skills 目录即可，`SKILL.md` 是该技能的唯一入口文件。

```bash
# Codex
git clone https://github.com/<you>/euclid-elements.git ~/.codex/skills/euclid-elements

# Claude Code
git clone https://github.com/<you>/euclid-elements.git ~/.claude/skills/euclid-elements
```

目录名必须与 `SKILL.md` 里 `name` 字段一致（`euclid-elements`）。

## 使用

技能靠 `description` 里的触发条件自动命中，也可以在提问时显式点名：

```
用 $euclid-elements 分析这个问题的第一性原理
```

典型适用场景：

- 要求「从第一性原理分析」
- 需要把隐含假设显式化
- 需要严格的「定义 → 公理 → 定理 → 证明」结构
- 审查一段论证里的隐含假设与循环论证
- 需要在保证正确率的前提下把方案做得更快

## 一个真实用例

用它分析过一道数学建模赛题（无线电干扰源的自动定位与清除）。技能的前置层直接逼出了两个决定性结论：

1. 判据是「100% 清除」而不是平均指标——这决定了方案必须包含覆盖性保证，不能只做贪心。
2. 瓶颈是移动距离而不是检测精度——20 分钟程序时限对应约 6000 m 的移动预算，于是方案的方向变成「压缩锚点数量与频道切换次数」。

在自建虚拟模拟器上，优化后的策略把总时间从 107.7 分钟压到 68.3 分钟（清除率 100%），程序运行时间约 5 ms/案例。

## 说明与边界

- 内容基于《几何原本》的通用数学内容（两千年来的公有领域文本）；**未引用任何特定中译本或出版版本的译文**。
- 技能管的是**结构**：它能保证论证不残缺、假设不漏、停止层不失控；它**不能**保证内容正确。物理学定律、经济常量、经验公式仍需自行核实。
- 技能内容为中文。
