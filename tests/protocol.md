# 测试协议

## 标准语料：牛顿《自然哲学的数学原理》

每次测试都用《自然哲学的数学原理》（Philosophiæ Naturalis Principia Mathematica）做语料。选它的理由：

- **它是欧氏公理化方法的真实移植**：定义 → 公理（运动三定律）→ Book III 的推理规则 → 逐条推出命题、定理、问题、引理、推论。结构与《几何原本》同型，但内容是物理，不是几何。
- **它含有真实的隐含假设**，这正是要检验的东西：绝对空间与时间、平方反比是设定而非导出、质点化处理、万有引力的普遍性、超距作用的机制缺失、离散冲量到连续力的极限步骤。
- **它逼出跨领域能力调用**：平面几何、极限／流数、天文观测数据、量纲与量级——正好测试「能力调用清单」是否真的点名了具体结论。

## 每次测什么

1. 从牛顿的定义与公理（运动三定律）出发，**尝试推导一个指定命题**。
2. 观察并记录三项机制是否真的起作用：
   - **能力调用清单**是否点名了具体结论（如「欧氏 I.38 同底等高」），而不是泛泛地说「用几何」；
   - **提问者公理检验**是否抓出 独立性／必要性／表述精度 问题（牛顿的公理与规则在此扮演提问者公理）；
   - **完备性审计**是否浮出未声明的假设——这是最有价值的产出。
3. 记录失败模式：把不确定写成「显然」、把牛顿的公理免检接受、清单膨胀、跳过待问环节。

## 用例清单

- [x] **Book I, Prop. 1（Theorem 1）**：等面积定律——由运动定律 I 与平面几何推出
- [ ] Book I, Prop. 6／11：由给定轨道反求力律
- [ ] Book III, Prop. 1–2：由开普勒定律推出平方反比
- [ ] Book III 规则 I–III：作为「提问者公理」接受检验
- [ ] Definition 3（vis insita）与 Law III 的相互独立性

## 用例记录模板

```
命题：
A 前置层：验收判据 / 目标与约束 / 重定义 / 假设排序 / 能力调用清单 / 待问（或降级） / 停止层
提问者公理检验：逐条 一致性·独立性·必要性·表述精度·可检验性·崩溃测试
B 论证层：[领域 | 依据] → 结论 的完整链条 + 标注出的未声明假设
C 收敛层：支配性约束 / 反证结果 / 能力缺口报告 / 结论先行
测试结论：三项机制各自是否生效；本次暴露的失败模式
```
