# 从第一性原理精准、高效解题

**这个技能不提供领域知识。** 它的职责是：把问题逼成一组显式对象（原语／公设／假设／目标／约束／结论），再为每个对象指明**该调用哪一类能力**去回答它。公理化在这里不是用来做证明的，而是**生成检索键、逼出隐式判断**的机制——隐式判断一旦被写成显式对象，「我其实没把握」的地方就会自己浮出来。默认行为倾向于模式匹配（把新问题塞进眼熟的旧框架），而这个协议的作用正是把 AI 已有的跨领域能力调到正确的位置上。

全流程三段：

```
A 前置层 · 精准：验收判据 → 目标/约束分离 → 问题重定义 → 假设排序 → 能力调用清单 → 向提问者提问 → 定停止层
B 论证层 · 严密：每步写成 演绎 [领域|依据] / 归纳 [warrant|强度|撤销条件] / 机制性断言（不入结论）
C 收敛层 · 高效：定位瓶颈 → 反证优先 → 两本账（能力缺口 / 机制性断言）→ 迭代回 A → 结论先行交付
```

**先出草案，再往下走**：A 层的产物先作为草案交给提问者核验，确认或修订后才进入论证。提问者的私有信息（口径、可得数据、不可动的约束）是 AI 推不出来的，只能问——空着不问就往下推，等于把假设偷偷塞进结论。

**先分析，后综合**：先从现象/事实归纳出原理，再由原理演绎出结论。两步都要，且**分析在前**。只有综合没有分析，得到的是一个漂亮但什么也不说的系统。

## 术语

- **第一性原理**：对当前问题不可再约的基础承诺 = 公设 + 公理 + 原语定义。**它不是自明真理**，而是当前最佳、且可能被推翻的归纳结果。
- **原语**：不定义、只命名并赋予用法的概念；定义链必须止于原语。
- **公设／公理**：分别指「允许做什么（操作）」与「允许断言什么（逻辑）」。
- **提问者公理**：由提问者给出的前提（经验判断、行业惯例、内部数据、「我们一直这么干」）。**它不是免检输入**，必须过下面的检验清单。
- **目标／约束**：要优化的量／不可违反的边界；必须分开列。
- **可放宽性**：每条假设标注 硬约束／可放宽／可替换；先攻可放宽的。
- **能力调用清单**：每条目标/约束/假设 → 所属领域 → 需要该领域回答什么 → 现在能否调用。**这是本技能的核心产物：它把隐式判断换成显式检索键。**
- **能力缺口**：依赖了当前无法调用的能力、只能靠假设撑住的那部分结论。
- **归纳步**：结论**超出前提**的步骤（有限观测→一般规律、同类迁移、最佳解释推断）。不能由演绎推出，只能声明 warrant、定界、并写明撤销条件。**与数学归纳法不同**——后者是演绎图式，按演绎步写即可。
- **机制性断言（假设）**：从现象推不出、但**有解释力**的机制性说法。它不许进入结论栏，只能留在待检验栏。
- **支配性约束（瓶颈）**：真正卡住问题的那个约束。
- **验收判据**：可观测的「算解决了」通过/失败条件。
- **停止层**：拆到足以回答验收判据即停的抽象层。
- **三准则**：一致性（不矛盾）、独立性（不可互相推出）、完备性（够推出结论）。
- **量词纪律**：假设与结论标注全称（∀）或存在（∃）。

## A 前置层 —— 定目标（管“精准”）

1. **写验收判据**：必须是可观测的通过/失败条件，不能是形容词。模板：`当 ____ 时算通过；当 ____ 时算失败`。若涉及“全部/最坏情形”，写清是平均还是最坏——这一条经常直接改变方案。口径若无法自定，转第 6 步去问。
2. **目标/约束分离**：两张清单，绝不混写。目标可折中，约束通常不可。哪些约束是真的不可动、哪些只是惯例，通常也要问（第 6 步）。
3. **问题重定义**：是否把手段当成了目标（XY 问题）？必要时改写问题陈述再继续。
4. **假设显式化并排序**：全部假设标 硬约束／可放宽／可替换，并指出最值得先试放宽的一条——高效解常来自放松一条看似必要的假设。提问者给的前提也在此登记，并过下一节检验清单。
5. **列能力调用清单**（核心步骤）：对每条目标、约束、假设，写出三件事——**领域**（它属于哪一类问题）、**需要什么**（该领域要给出公式、经验规律、已知定理、量级基准还是数据）、**可调用性**（现在能调用／需要外部资料／只能假设）。写不出领域，说明还没真正理解这条假设；写不出「需要什么」，说明还不知道自己缺什么。
   **只登记「判断错了就会改变方案」的条目**，其余略过——清单越长越像形式主义。最后标出**最关键的那一条能力缺口**，它决定停止层停在哪里。
   「过滤规则」和「优先级」里有相当一部分不是 AI 能定的（取决于提问者所处的决策语境），这部分直接转第 6 步去问。
6. **向提问者索取私有信息**：有三类信息 AI 无法先验判断，只能问——
   - **口径**：验收判据是按平均还是最坏？谁来验收？
   - **可动性**：哪些约束真的不可动，哪些只是沿用惯例？
   - **可得性**：能力清单里哪些数据/结论实际拿得到、代价多大？
   问法：**给候选选项（闭合问题）比开放式省力**；一次只问最关键的 1–3 个，并说明「为什么问」以及「不同答案会怎样改变方案」。
   **无人可问时**（自动化、批处理、提问者不在场）：把整张「待问清单」降级为显式假设，全部计入 C 层的登记表，并把停止层前移到「在无提问者条件下能诚实作答的那一层」——不要替提问者默认一个答案。
7. **定停止层**：够用即停。判断标准：再往下拆一层，验收判据的答案会变吗？不变就停。若某条关键能力不可调用，停止层应前移到「能诚实作答的那一层」，而不是继续往下空推。

## 提问者提供的公理：必检

提问者给出的前提**不是免检输入**。对每一条：

- **一致性**：与其它公理、与已核实的事实矛盾吗？
- **独立性**：它其实能由别的公理推出吗？能推出 → 它是定理，降级，不要占公理的位置。
- **必要性**：把它删掉，结论会变吗？不变 → 冗余，删掉。
- **表述精度**：量词、适用范围、时间效力写清了吗？（「需求不变」是对谁不变、多久不变、在什么条件下不变？）
- **可检验性**：能被数据证伪吗？来源是实测、经验还是权威？
- **崩溃测试**：它要是错了，方案哪里会塌？——这直接决定它在清单里的优先级。

不要为了让提问者舒服而默认接受一条未经验证的公理。这是本环节最主要的失败模式。

## B 论证层 —— 按需严谨（管“严密”）

按复杂度分层投入，防止简单问题被过度公理化：

- **简单**：直接给可执行解 + 关键假设 + 残留风险，不建公理化。
- **中等**：假设显式化 + 推理要点 + 反证抽查。
- **复杂/高风险**：启用完整骨架——命题陈述（量词写全）→ 设定 → 规定（含可行性条件与唯一性）→ 只用公设构造 → 推理链 → 结论收回一般性；再查三准则。

**推理链有三种步，写法和地位都不同：**

- **演绎步**　`[领域 | 依据] → 结论`　依据 = 调用到的领域结论／已证命题／提问者公理。
- **归纳步**　`[归纳 | warrant | 强度 | 撤销条件] → 结论`　结论超出前提。warrant 说明凭什么推（样本枚举／同类迁移／最佳解释）。**撤销条件必须写明「出现什么观测就推翻它」——写不出撤销条件的，不是归纳，是臆造。**
- **机制性断言**　`[假设 | 无现象授权]`　有解释力但推不出来。**永远不进入结论栏**，只进待检验栏。

某一步找不到演绎依据时，**先判它属于哪一种**：调不到能力 → **能力缺口**；有 warrant 且可撤销 → **归纳步**；两者都不是 → **机制性断言**。三者都要登记，处理方式不同。

其中**完备性最常出问题**：专门找「大家都默认、却从未被声明」的步骤（历史上连「两圆必有交点」都属这类缺口）。

## C 收敛层 —— 出解 + 迭代（管“高效”）

1. **定位支配性约束**：只攻真正卡住问题的那个，别在次要约束上耗力。
2. **反证优先**：先用最小成本找反例证伪，证伪失败再上证明。归纳步的撤销条件就是它的反例句。
3. **出两份登记表**：
   - **能力缺口**：靠假设撑住、没真正调用到能力的结论；
   - **机制性断言**：推不出但有解释力的说法。
   两者都是最脆弱处，都必须显式交付；**第二类不得以结论形式出现**。
4. **迭代闭环**：验证失败 → 回 A 修订假设/目标/停止层 → 重走一轮。
5. **结论先行交付**：先给结论，再给依据要点与两份登记表。

## 通用手法（跨领域可调用）

- **反证**：假定反面，导出矛盾。
- **构造**：先确立对象存在（或可造），再论证其性质。
- **极端情形**：取 0、∞、边界、退化情形——最快暴露错误假设的手段。
- **量纲／量级**：先校验量纲，再估数量级，用数量级否掉不可能的方案。
- **守恒与不变量**：找过程中不变的东西（能量、质量、总时间、总距离）。
- **倒推**：假定所求已成，反推到已知，再把链条倒过来构造解法。
- **分情形**：穷尽列举，逐一支。
- **分析与综合**：先由现象归纳出原理（分析），再由原理演绎出结论（综合）。分析在前。
- **叠合／穷竭**：几何与极限问题的专用手法（可重合即相等；证既不大于也不小于）。

## 审计要点

- **能力缺口的伪装**：把「我不确定」写成「显然」「容易看出」。最高频，也最难自查。
- **提问者公理免检**：把提问者给的前提直接当公理用，既没验证也没标注。第二高频。
- **归纳步伪装成演绎步**：「由此可得」「显然可以推广」「同理适用」——隐藏「我超出了前提」。
- **机制性断言伪装成结论**：用「因为…所以…」的句式包装一个从现象推不出的解释。和上一条是一对。
- **隐含假设**：使用了未列为公设/公理/已证命题的信念。
- **循环论证**：某步用到了待证结论；**循环定义**：定义之间成环。
- **量词偷换**：用特例代替全称（必要/充分混淆）。
- **完备性**：结论是否真能从已声明的前提出发走完。
- **独立性／一致性**：有公理能由其余推出（→ 降为定理）？有两条互相矛盾？
- **过度公理化**：简单问题被全量骨架拖慢。

## 输出格式

```
【A 前置 · 待核验】验收判据 / 目标 / 约束 / 假设（含可放宽性） / 能力调用清单 / 停止层
【待问】口径、可动性、可得性 —— 只问最关键的 1–3 个，附「为什么问 + 不同答案的影响」；无人可问时整体降级为显式假设
【提问者公理检验】逐条过 一致性/独立性/必要性/表述精度/可检验性/崩溃测试
【B 论证】复杂度；三种步混排：[领域|依据]（演绎）／[归纳|warrant|强度|撤销条件]／[假设|无现象授权]
【C 收敛】支配性约束 → 反证抽查 → 两本账（能力缺口 / 机制性断言）→ 结论（先行，标明是演绎保证还是归纳支持） → 残留风险
```

## 完成标准（五问收口）

- **精准**：验收判据已定义且结论通过；目标与约束已分离；问题已核对无 XY。
- **可调用**：每条依赖都标明了来源——领域能力／提问者公理／归纳步／自己的假设，四者不混淆；提问者公理已逐条过检验清单。
- **高效**：停在够用的抽象层；已定位支配性约束；先用反证抽查而非全量证明。
- **严密**：假设显式、量词完整、结论标明是**演绎保证**还是**归纳支持**；机制性断言不在结论栏；三准则已答复。
- **可执行**：结论先行、下一步明确；能力缺口、未验证的提问者公理、机制性断言与残留风险都已声明。
